## Confirmed sound
- Every published package has `publishConfig.access: public`, `files` allow-lists and `sideEffects: ["*.css"]`; dual `import`/`require` conditions with `types` first (C).
- Add-ons depend only on ui and core, matching `.ai/PROJECT.md` boundaries; editor uses no core import, consistent with its deps (C: grep found none).
- The `vue2/` and root `styles.css` folders listed in `files` are build-generated and untracked (C: `git ls-files` empty) so `files` must keep pointing at them.
