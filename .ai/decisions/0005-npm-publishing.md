# Decision
Publish the 9 packages to npm under the `@squirkle-ui` organization (renamed from `@squirkle`, whose npm org belongs to another account), with `.d.ts` types generated by `vue-tsc`, `workspace:^` internal ranges, and a manual release run by the user.

## Context
The packages shipped JavaScript only, had no LICENSE/README in the package folders, defaulted to restricted scoped access, and pinned internal deps exactly (`workspace:*`). Guardrails forbid the agent from publishing or bumping versions.

## Decision
- Types: `packages/<pkg>/tsconfig.build.json` + `vue-tsc` after the Vite builds → `dist/types`; `types` first in `exports` for `.` and `./vue2`; `./dist/types/*` export for cross-package inferred types (`scripts/build.mjs` rewrites sibling paths).
- Manifests: `publishConfig.access: public`, `repository` (+ `directory`), `homepage`, `bugs`, `keywords`; internal deps `workspace:^`.
- LICENSE (MIT, KheangLov) at the root and in each package; a README per package.
- Release: verified with `pnpm pack` + scratch consumer apps; published by the user with `pnpm -r publish --access public`.

## Alternatives
`vite-plugin-dts` (new dependency); separate Vue 2 type builds (two type sets to maintain); unscoped names; Changesets for versioning (deferred).

## Consequences
Build is slower (~6 s more for types). Vue 2.7 TypeScript users receive Vue 3-based types (unverified). Versions are bumped by the user; a versioning tool can be added later.

## Affected Areas
`packages/*/package.json`, `packages/*/tsconfig.build.json`, `scripts/build.mjs`, LICENSE/README files.
