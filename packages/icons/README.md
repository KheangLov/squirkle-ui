# @squirkle/icons

Iconify integration and icon browser for Squirkle UI.

```bash
npm i @squirkle/icons @squirkle/ui
```
```ts
import { SqIconPicker } from '@squirkle/icons'        // Vue 3
// import { SqIconPicker } from '@squirkle/icons/vue2' // Vue 2.7
import '@squirkle/icons/styles.css'
```
Peer dependencies: `vue`, `@squirkle/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
