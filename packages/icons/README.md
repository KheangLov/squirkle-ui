# @squirkle-ui/icons

Iconify integration and icon browser for Squirkle UI.

```bash
npm i @squirkle-ui/icons @squirkle-ui/ui
```
```ts
import { SqIconPicker } from '@squirkle-ui/icons'        // Vue 3
// import { SqIconPicker } from '@squirkle-ui/icons/vue2' // Vue 2.7
import '@squirkle-ui/icons/styles.css'
```
Peer dependencies: `vue`, `@squirkle-ui/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
