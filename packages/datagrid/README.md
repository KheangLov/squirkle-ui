# @squirkle/datagrid

Enterprise-grade virtualized data grid for Squirkle UI.

```bash
npm i @squirkle/datagrid @squirkle/ui
```
```ts
import { SqDataGrid } from '@squirkle/datagrid'        // Vue 3
// import { SqDataGrid } from '@squirkle/datagrid/vue2' // Vue 2.7
import '@squirkle/datagrid/styles.css'
```
Peer dependencies: `vue`, `@squirkle/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
