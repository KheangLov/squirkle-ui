# @squirkle/swiper

Touch swiper / carousel for Squirkle UI.

```bash
npm i @squirkle/swiper @squirkle/ui
```
```ts
import { SqSwiper } from '@squirkle/swiper'        // Vue 3
// import { SqSwiper } from '@squirkle/swiper/vue2' // Vue 2.7
import '@squirkle/swiper/styles.css'
```
Peer dependencies: `vue`, `@squirkle/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
