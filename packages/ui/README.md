# @squirkle/ui

Squircle-first Vue component library for Vue 2.7, Vue 3 and Nuxt 2/3/4.

```bash
npm i @squirkle/ui vue
```
```ts
// Vue 3
import { createSquirkle } from '@squirkle/ui'
import '@squirkle/ui/styles.css'
app.use(createSquirkle())

// Vue 2.7
import { createSquirkle } from '@squirkle/ui/vue2'
import '@squirkle/ui/styles.css'
Vue.use(createSquirkle())
```
Nuxt: use [`@squirkle/nuxt`](https://www.npmjs.com/package/@squirkle/nuxt).
