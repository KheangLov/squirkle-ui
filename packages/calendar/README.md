# @squirkle/calendar

Event calendar (month / week / day) for Squirkle UI.

```bash
npm i @squirkle/calendar @squirkle/ui
```
```ts
import { SqCalendar } from '@squirkle/calendar'        // Vue 3
// import { SqCalendar } from '@squirkle/calendar/vue2' // Vue 2.7
import '@squirkle/calendar/styles.css'
```
Peer dependencies: `vue`, `@squirkle/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
