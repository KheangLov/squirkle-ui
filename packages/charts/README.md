# @squirkle/charts

Lightweight SVG charts with squircle styling for Squirkle UI.

```bash
npm i @squirkle/charts @squirkle/ui
```
```ts
import { SqLineChart } from '@squirkle/charts'        // Vue 3
// import { SqLineChart } from '@squirkle/charts/vue2' // Vue 2.7
import '@squirkle/charts/styles.css'
```
Peer dependencies: `vue`, `@squirkle/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
