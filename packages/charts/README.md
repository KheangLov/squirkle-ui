# @squirkle-ui/charts

Lightweight SVG charts with squircle styling for Squirkle UI.

```bash
npm i @squirkle-ui/charts @squirkle-ui/ui
```
```ts
import { SqLineChart } from '@squirkle-ui/charts'        // Vue 3
// import { SqLineChart } from '@squirkle-ui/charts/vue2' // Vue 2.7
import '@squirkle-ui/charts/styles.css'
```
Peer dependencies: `vue`, `@squirkle-ui/ui`.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
