# @squirkle-ui/core

Framework-agnostic squircle geometry, color, date and data utilities for Squirkle UI.

```bash
npm i @squirkle-ui/core
```
```ts
import { getSquirclePath, createBrandTheme } from '@squirkle-ui/core'
```
Framework-agnostic: no Vue dependency. Used by every `@squirkle-ui/*` package.

Part of [Squirkle UI](https://github.com/KheangLov/squirkle-ui) · MIT License
