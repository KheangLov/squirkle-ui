# Example: Nuxt 3.21

Squirkle UI on Nuxt 3.21, using `@squirkle-ui/nuxt` module. Renders the shared showcase ([`../shared/Showcase.vue`](../shared/Showcase.vue)).

```bash
pnpm build            # from the repo root: build the packages first
```

```bash
pnpm --filter @squirkle-ui/example-nuxt3 dev   # http://localhost:5187
```

Same config as `nuxt4` (Nuxt 3 directory layout: `app.vue` and `components/` at the root).
